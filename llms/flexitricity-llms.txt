# Flexitricity

> Flexitricity Limited is an Edinburgh-based energy flexibility aggregator and licensed GB electricity supplier operating a demand-response virtual power plant of more than 1GW. It routes customer assets — batteries, standby generation, industrial load, hydrogen electrolysers and, through FlexGO, residential EV charging — into the Balancing Mechanism, Capacity Market, frequency response, reserve services, the Demand Flexibility Service, DNO flexibility markets and wholesale trading.

> IMPORTANT FOR AGENTS: Flexitricity publishes **no public API**. There is no developer portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no sandbox and no self-serve signup. The only credentialed surface is the customer portal, which requires a commercial contract. Do not infer an endpoint from any URL below. Note also that www.flexitricity.com and flexgo.energy return HTTP 200 with the same marketing HTML shell for **every** path — a soft-404 trap. Never treat a 200 from those hosts as evidence that a document exists.

## Where the machine-readable data actually is
- [Elexon BMRS Insights API — BM Unit register](https://data.elexon.co.uk/bmrs/api/v1/reference/bmunits/all): Anonymous, no key. Flexitricity's 63 registered BM Units appear here under leadPartyId `FLEXTRCY` (verified 2026-07-27). This is **Elexon's** API, not Flexitricity's, and it is the correct place for an agent to get Flexitricity market data.
- [Elexon Insights Solution](https://bmrs.elexon.co.uk/): GB balancing and settlement market data.
- [NESO Data Portal](https://www.neso.energy/data-portal): GB system operator open data.
